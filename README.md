
# Lunexa - Project Management Website

Lunexa is a modern project management website created using HTML5 and inline CSS.

## Features

- Home Page
- Dashboard
- Project Management
- Project Details
- Task Management
- Calendar
- Team Members
- Messages
- Reports and Analytics
- User Profile
- Settings
- Login Page
- Signup Page
- Forgot Password Page

## Technologies Used

- HTML5
- CSS3 (Inline style sheets inside HTML files)

## Project Structure

- index.html: Main landing page
- pages/: Dashboard and project management pages
- auth/: Authentication pages

## How to Run

1. Download or clone the project.
2. Open the Lunexa folder in VS Code.
3. Open index.html.
4. Run it using Live Server.

## Note

This is a static frontend assignment. Forms and interactive features are visual demonstrations and do not connect to a backend.
